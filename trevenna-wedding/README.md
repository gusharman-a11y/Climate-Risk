# Trevenna Wedding Shop page

A single-file, self-contained landing page for Trevenna wedding venue (St Neot, Cornwall),
modelled on the layout and tone of placesandspacesartco.com/wedding-shop — hero, warm intro
copy, a "shop" grid of offerings with prices, testimonial band, venue overview, how-it-works
steps, FAQs and a contact CTA.

- `index.html` — the whole page: inline CSS and hand-drawn-style inline SVG illustrations,
  no external assets, fonts or scripts. Open it directly in any browser.

Venue facts (142 acres, exclusive use, sleeps 45, 120 day / 150 evening guests, weddings
from £9,635, Threshing Barn from £760/night, contact details, viewing times) are taken from
trevenna.co.uk and public listings. Prices for the gift card and venue illustration keepsake
are placeholders — confirm with the venue before publishing.
